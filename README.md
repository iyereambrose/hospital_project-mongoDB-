# Hospital Management System

A web application project designed to manage hospital-related information and patient records using a database-backed application.

## 🚀 Project Overview

The Hospital Management System is a software development project focused on organizing patient information and supporting basic hospital data management operations.

## 🛠️ Technologies Used

- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Database ODM:** Mongoose
- **Development Tools:** Git, GitHub, Postman

## ✨ Features

- Patient record management
- Database integration with MongoDB
- Backend API development
- Structured application configuration using environment variables

## 📋 Prerequisites

Before running the project, install:

- Node.js and npm
- MongoDB, or access to a MongoDB Atlas database
- Git

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/iyereambrose/hospital_project-mongoDB-.git
   ```

2. Enter the project directory:

   ```bash
   cd hospital_project-mongoDB-
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file in the appropriate backend directory and configure the required environment variables, including your MongoDB connection string and port.

   **Security:** Never commit database credentials, passwords, or secret keys to GitHub.

5. Start the application using the script defined in `package.json`. For example, if the project defines a `start` script:

   ```bash
   npm start
   ```

## 🧪 Testing

Use Postman or another API client to test the endpoints implemented in the project.
